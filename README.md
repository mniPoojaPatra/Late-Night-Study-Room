# Late Night Study Room

A cozy real-time virtual study cafe built with React, Vite, Tailwind, Framer Motion, Express, and Socket.io.

## Run Locally

```bash
npm install
npm run dev
```

In another terminal:

```bash
npm run server
```

Copy `.env.example` to `.env` before running the backend.

## Deploy Later

The frontend is ready for Netlify with `netlify.toml`. The backend lives in `server/` and can be deployed separately to Render or Railway.
